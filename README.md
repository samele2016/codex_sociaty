# 社区助手

一个面向小区邻里的微信原生小程序框架，使用微信云开发承载数据库、云函数和云存储。

## 首版能力

- 邻里信息流：闲置物品、技能交换、兴趣搭子、装修心得、商家广告、社区团购、闲聊论坛、求助互助。
- 邀请码/楼栋认证：未认证用户可浏览，认证后才能发布、评论、查看联系方式。
- 帖子互动：评论、点赞、收藏、举报、置顶、精华、下架。
- 管理后台：审核待审帖子、处理举报、封禁用户、查看基础统计。
- 内容安全预留：云函数中集中接入文本安全检测，图片审核留有扩展点。

## 目录结构

```text
miniprogram/             小程序端页面、样式、工具方法
cloudfunctions/          微信云函数
docs/                    数据库集合、索引、运营规则说明
```

## 本地使用

1. 用微信开发者工具导入本目录。
2. 在 `project.config.json` 中替换真实 `appid`。
3. 在 `miniprogram/app.js` 中替换 `env` 为你的云开发环境 ID。
4. 在云开发控制台创建 `docs/database.md` 中的集合和索引。
5. 逐个上传并部署 `cloudfunctions` 下的云函数。

## 默认规则

- 普通分类帖子自动发布。
- 商家广告、社区团购默认进入待审核。
- 未认证或被封禁用户不能发布、评论、查看联系方式。
- 首版不接入支付、订单、私信和担保交易。
