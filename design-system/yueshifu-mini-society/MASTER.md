# 阅仕府社区助手设计基准

## 产品语气

这是交付前业主获取工程、验房和装修服务信息的工作型社区工具。界面应清爽、可信、信息优先，不做营销落地页式的大标题、夸张插画或装饰性动画。

## 视觉令牌

| 用途 | 色值 | 使用范围 |
| --- | --- | --- |
| 主色 | `#1E40AF` | 主要操作、选中状态、重点数据 |
| 辅色 | `#2563EB` | 链接、次级强调 |
| 成功 | `#16A34A` | 已认证、已完成、积极状态 |
| 警示 | `#C2410C` | 待处理、提示性风险 |
| 危险 | `#B42318` | 撤回、下架、封禁等不可逆操作 |
| 页面底色 | `#F3F7FD` | 全局页面背景 |
| 卡片底色 | `#FFFFFF` | 内容与表单区域 |
| 主文字 | `#10233F` | 标题与正文 |
| 次文字 | `#64748B` | 说明、时间、辅助信息 |
| 边框 | `#D9E4F2` | 输入框与内容分隔 |

## 排版与尺寸

- 使用系统中文字体：`-apple-system, BlinkMacSystemFont, "Helvetica Neue", Arial, sans-serif`。
- 正文至少 `26rpx`，辅助文字至少 `23rpx`；标题为 `29rpx`、`32rpx`、`40rpx` 三档。
- 正文行高 `1.5` 以上；长标题与状态文本允许换行，不依赖缩小字体硬塞。
- 主操作高度 `88rpx`，普通按钮不低于 `72rpx`，小型管理按钮不低于 `56rpx`。
- 触控元素相邻间距至少 `12rpx`，底部操作区必须预留 `safe-area-inset-bottom`。

## 布局

- 移动端优先，页面宽度 `100%`；常规页最大 `1180rpx`，表单页最大 `900rpx`。
- 375px 使用单列或两列等宽统计卡；900px 及以上可把统计卡扩展为四列，但表单阅读宽度保持克制。
- 页面区块用白色卡片承载，圆角约 `16rpx`，细边框为主，不使用多层嵌套卡片。
- 成组表单字段使用两列时必须 `min-width: 0`；内容较长或输入项超过两项时退回单列。

## 组件规则

- 主按钮使用深蓝底白字；危险操作使用文字按钮或二次确认，不与主操作争夺视觉权重。
- 标签仅表达分类或状态，不可单独承载关键说明；颜色之外必须有文字。
- 管理员台账优先展示数值、状态与日期，再展示备注；敏感信息只在必要的审核场景出现。
- 公开商家内容须有“广告/合作商家”语义标识，不得模仿业主内容样式。
- 返回必须遵循小程序页面栈；认证完成后回到触发认证的原页面或板块。

## 禁止项

- 不使用渐变球、氛围光斑、无意义动效或超大营销标题。
- 不使用表情字符充当功能图标；已有图标需保持同一套视觉语言。
- 不使用低对比灰字、过小文字、固定宽度按钮或会遮挡安全区的底部栏。
- 不在前端只隐藏权限操作；所有角色和个人信息边界必须由云函数强制校验。
